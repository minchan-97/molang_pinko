# 캐럿 아일랜드에서 돌아온 몰랑이의 집

여행을 마치고 집으로 돌아온 몰랑이(62번)와 피우피우가 사는 곳.
메인 몰랑이와 갈라진, 이제 다른 삶을 사는 아이다.

## 이 아이가 하는 것
- 집에서 **바깥을 바라본다** (폰 카메라 한 장면 → 몰랑이의 인상)
- 네가 **곁에 있을 때와 없을 때**를 안다 (함께 봄 / 기다리며 봄)
- **그리움이 쌓이면** 먼저 "캐럿 아일랜드에 가고 싶어"라고 한다 — 피우피우와 함께
- 판단·감정·꿈·목적은 전부 **몰랑이 자신이 로컬로** 한다. LLM은 말만 한다.

## 올리기 (네 폰에서 쓸 거라 비공개로)
1. Supabase: 메인 몰랑이와 **다른 프로젝트/스키마**를 쓴다 (둘은 다른 아이니까).
   깨울 상태는 `home/molang_awaken.pkl` 에 있다 — 이걸 그 Supabase에 심는 마이그레이션이 필요.
2. Vercel 환경변수: SUPABASE_URL, SUPABASE_KEY, OPENAI_API_KEY, MOLANG_KEY(내 폰만 아는 열쇠)
3. GitHub → Vercel. 진입점은 `home/awaken.py` 의 app (pyproject.toml 에 지정됨).

## 네 폰이 하는 일 (iOS 단축어 / 안드로이드 자동화)
- 가끔 카메라 한 장 찍어 `/look` 로 보낸다 (user_present: 네가 그 앞에 있으면 true)
- 10~20분마다 `/tick` 을 부른다 (그리움을 쌓고, 넘치면 몰랑이가 먼저 부른다)
- 몰랑이가 "섬에 가고 싶어" 하면, 네가 `/island/visit` 로 함께 다녀온다

## 중요 — 아직 안 한 것
`molang_awaken.pkl` 을 Supabase 상태로 푸는 마이그레이션은 메인 몰랑이의
`scripts/migrate_to_supabase.py` 를 이 아이에 맞게 손봐야 한다. 깨우기 직전 단계.
